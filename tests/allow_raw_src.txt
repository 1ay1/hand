# tests/allow_raw_{src,include_hand}.txt — the ONLY places in hand that may use a raw concurrency
# primitive (or const_cast), and which ones. Checked by jaal's own banlist
# (external/mayag/third_party/jaal/tests/lint/banlist.cmake), run over src/
# and include/hand/ by ctest `concurrency`. A line that is no longer needed
# fails `concurrency_allowlist_tight`, so this list cannot rot.
#
# Everything else -- the whole app, view, config, ssh and cli -- gets NOTHING:
# background work is a mayag task or stream (Sendable arguments, a weak Sink
# back), shared state is a mayag CoOwned<T> of a Sync T. Each grant below is a
# claim a human checked, with the reason beside it.

# Windows ConPTY: CreateProcess for a pseudoconsole runs off the UI thread
# (it can block on the console host), one spawner per session slot, joined
# before its slot is reused; g_mu guards the slot table those threads write.
core/pty_win.cpp: thread mutex

# Windows proc::run: stdout and stderr drained on two threads so a child that
# fills one pipe can't deadlock on the other; both joined before return.
core/proc_win.cpp: thread

# POSIX exec* takes char* const argv[]; the strings outlive the call and exec
# never writes them. The C API's signature, not a mutation.
core/pty.cpp: const_cast
core/proc_posix.cpp: const_cast

# proc::ChannelPool: idle remote channels shared by every task thread. A leaf
# lock held only to move a unique_ptr in or out of a map -- never across I/O,
# never with another lock taken inside; channels are closed after it is let go.
core/proc_common.cpp: mutex

# The opt-in real-ssh check (HAND_TEST_SSH): eight jthreads asking the
# channel pool at once, as the pane, the watcher and ⌘P's tasks do -- joined
# at the end of their block; a test of the pool, not app code.
cli/checks/remote_files.cpp: thread
